# E-Commerce Sales Analyzer

A Python-based E-Commerce Sales Analyzer that reads order data from a CSV file, processes sales information, generates revenue summaries, and visualizes sales performance using charts.

## Features

- **Load Order Data:** Reads order information from a CSV file (`orders.csv`).
- **Data Validation:** Checks for missing information and invalid quantities or prices.
- **Duplicate Detection:** Identifies and skips duplicate Order IDs.
- **Sales Summary:** Displays:
  - Total Revenue
  - Total Number of Orders
  - Total Units Sold
  - Top-Selling Product
  - Top 5 Products by Revenue
- **Category-wise Revenue:** Calculates revenue and percentage contribution for each category.
- **Pie Chart:** Visualizes category-wise revenue distribution.
- **Bar Chart:** Displays the top 5 products by revenue.
- **Interactive Menu:** Allows users to select different analysis options.

## CSV File Format

The project requires an `orders.csv` file containing the following columns:

| Column Name | Description |
|---|---|
| Order_ID | Unique order identification number |
| Product | Name of the product |
| Category | Product category |
| Quantity | Number of units purchased |
| Price | Price per unit |

### Sample orders.csv

```csv
Order_ID,Product,Category,Quantity,Price
101,Laptop,Electronics,2,50000
102,Mobile,Electronics,3,15000
103,Chair,Furniture,4,2500
104,Table,Furniture,2,5000
105,Headphones,Accessories,5,1000
106,Keyboard,Accessories,3,1500
```

**Note:** Quantity and Price must contain positive numeric values. Each Order_ID must be unique.

### Menu Options

**1. Summary**

Displays the overall sales performance, including total revenue, orders, units sold, top product, and top 5 products by revenue.

**2. Category-wise Revenue and Pie Chart**

Displays revenue generated by each product category along with its percentage contribution. It also generates a pie chart.

**3. Top 5 Products Bar Chart**

Generates a bar chart showing the five products with the highest revenue.

**4. Exit**

Closes the application.

## Data Validation

The program automatically handles invalid data:

- Skips rows with invalid Quantity values.
- Skips rows with invalid Price values.
- Skips rows where Quantity or Price is zero or negative.
- Skips rows with missing Order_ID, Product, or Category.
- Detects duplicate Order_ID values and keeps only the first valid occurrence.
- Displays appropriate error messages when the CSV file is missing or required columns are unavailable.

## Revenue Calculation

Revenue is calculated using the following formula:

```text
Revenue = Quantity × Price
```

Total revenue is calculated by adding the revenue of all valid orders.
